Executive Summary

The accessibility evaluation of the "Katora" website was conducted following the WCAG 2.1 guidelines. The evaluation examined the website across the four principles: Perceivable, Operable, Understandable, and Robust.

Scope of the Evaluation

Website name
Katora
Scope of the website
The evaluation covers the homepage of the “Katora” website (single static HTML page). The assessment includes the header navigation menu, promotional banner, product listings, special offers section, category sections, newsletter form, and footer navigation. The evaluation considers images, links, headings structure, navigation, forms, and interactive elements. External links and third-party content are not included in this evaluation.
WCAG Version
2.2
Conformance target
AA
Accessibility support baseline
Chrome, Firefox, Edge.
Additional evaluation requirements
Not provided
